# AI Council – GitHub Pages setup
1. Create a repo. Upload these files to the ROOT (not inside a folder, and not the .zip):
   index.html, manifest.webmanifest, apple-touch-icon.png, icon-192.png, icon-512.png
2. Repo > Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. Wait 1-2 minutes, then open https://USERNAME.github.io/REPO/ in Safari (not the github.com file page).
4. Share > Add to Home Screen. If you added an older version, delete that icon first.
If something fails, a red error bar at the top of the page tells you why.
